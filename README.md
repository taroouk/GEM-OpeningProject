# 🎨 Grand Egyptian Museum Opening 2025 — Event Website

## 📖 Overview

This project is a **front-end event landing page** created to promote the **Grand Egyptian Museum Opening in 2025**.
It highlights event details, speakers, schedule, registration, and interactive experiences using a **modern, responsive design**.

The website combines **HTML, CSS, Bootstrap, JavaScript, and jQuery** to deliver an elegant user experience with smooth animations and interactivity.

---

## 🏗️ Features

### 🖥️ **Intro Animation**

* A fullscreen animated intro displaying the museum name and opening year.
* Smooth fade-out transition to the main content.

### 🏛️ **Hero Section**

* Prominent event title, date, and location.
* “Get Tickets” and “View Schedule” buttons.
* Countdown timer dynamically updating to the event date.

### ⏰ **Event Schedule**

* Organized grid layout showing all key times and activities.
* Clean, responsive design for both desktop and mobile.

### 🎤 **Speakers Section**

* Highlighted guest speakers with images and titles.
* Responsive grid with hover and image-card effects.

### 🏺 **Event Experiences**

* Dual-image display showcasing the **Discovery Challenge** and **Mixed Reality** experiences.
* Includes text descriptions and a CTA button.

### 🔠 **Hieroglyph Translation Tool**

* “Hieroglyph Name Converter” that converts typed names into stylized hieroglyphic visuals.
* Buttons for “Convert,” “Clear,” and “Copy Result.”

### 📝 **Registration Form**

* Modern registration form with validation and styled inputs.
* Category dropdown (Guest, Press, VIP).
* Terms of service checkbox and Google sign-up option.

### 🖼️ **Slideshow Section**

* Horizontal scrolling carousel titled “Journey Through Egypt’s Wonders.”
* Showcases multiple museum-related images with animation.

### 📍 **Location Section**

* Embedded Google Maps for easy navigation.
* Key event info (date, time, venue) and a “Get Directions” button.

### ⚓ **Footer**

* Navigation links for all sections.
* Museum branding and copyright.
